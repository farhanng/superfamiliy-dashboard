### True Root Cause

**The email `farhan.naufalghani@gmail.com` simply does not exist in the `whitelist_users` Firestore collection.**

The OAuth callback flow:
1. User authenticates with Google ✅
2. Backend receives OAuth callback with auth code ✅
3. Backend calls `CheckWhitelist(userInfo.Email)` → queries Firestore
4. Firestore returns no document for this email
5. `allowed: false` → backend shows "Failed to check whitelist" error

**This is a data problem, not a code or configuration problem.**
