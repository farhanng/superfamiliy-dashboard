# SuperFamily Dashboard

PWA sederhana untuk keluarga Farhan & Inne.

## 6 Fitur MVP

1. 💰 Tracking Budget & Pengeluaran
2. 📅 Tanggal-Tanggal Penting
3. 🍽️ Weekly Meal Plan + Jadwal Mingguan
4. 🎯 Jadwal Aktivitas Weekend Produktif
5. 🔔 Pengingat Pajak (PBB, SIM, dll)
6. 📬 Tagihan (Air, IPL, Cicilan)

## Tech Stack

- **Frontend:** Vanilla JS / Preact + Tailwind CSS
- **Storage:** IndexedDB via Dexie.js
- **PWA:** Vite + vite-plugin-pwa
- **Offline-first:** Ya
